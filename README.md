
# PokeJS


PokeJS is an app to find and save pokemons in your own pokedex 

## API

PokeJS uses the [PokéAPI v2](https://pokeapi.co/docs/v2) REST API. The app
loads the 151 Pokémon of Generation I and fetches details and evolution chains
when needed. Responses are cached for the current app session.


## Live-Preview

https://echw.github.io/poke_js/




## How to run it locally?

Clone the project

```bash
  git clone https://github.com/Echw/poke_js.git
```

Go to the project directory

```bash
  cd poke_js
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
    
## Tech Stack

**Client:** React, TypeScript, SCSS
